# TwinEdit project page

Static project page for **TwinEdit: Consistent Object Replacement for Multi-View Robot Video Editing**. Open `index.html` locally to preview it. All styles, scripts and media are served from relative paths.

## GitHub Pages

Commit these files to the root of the site repository. In **Settings → Pages**, select **Deploy from a branch**, the site's branch (typically `main`) and **/ (root)**. The included `.nojekyll` lets GitHub Pages serve the static files directly. See [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
